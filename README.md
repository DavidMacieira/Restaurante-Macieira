## Publicacao pronta

Partilho o projeto Macieira, um website conceptual para um restaurante de cozinha portuguesa.

O objetivo foi criar uma experiência digital que apresentasse o restaurante e o menu de forma clara, mantendo uma identidade visual consistente. O site inclui uma página inicial com galeria, um menu bilingue organizado por categorias, um formulário visual de pedido de reserva e uma área administrativa demonstrativa.

Foi desenvolvido com React e Vite, usando Tailwind CSS para os estilos, React Router para a navegação e Framer Motion para as animações. O projeto também guarda a preferência de idioma no navegador.

Neste momento, o envio de reservas e a persistência de dados ainda não estão ligados a um backend; o formulário e o painel representam a camada de interface do projeto.
